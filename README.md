# Dashboard Financeiro para PMEs

Dashboard financeiro automatizado que transforma planilhas de vendas em relatorios profissionais em PDF, feito para pequenas e medias empresas que ainda controlam tudo manualmente.

## Sobre o projeto

Este projeto conecta a uma planilha de vendas do Google Sheets, processa os dados automaticamente e entrega:

- Dashboard interativo com vendas, lucro, ticket medio, produtos mais vendidos e tendencias
- Relatorio em PDF gerado automaticamente, pronto para contador, socios ou investidores

## Tecnologias

- Python
- Streamlit
- pandas
- Google Sheets API
- reportlab (geracao de PDF)
